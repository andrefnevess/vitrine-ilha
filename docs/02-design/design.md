# Design

**Arquivo no Figma:** _link a adicionar_

## Telas

Cada tela é desenhada em duas larguras: celular (375 px) e desktop (1440 px).

| Tela | Rota | Componentes |
| --- | --- | --- |
| Vitrine | `/` | `Header`, `SearchBar`, `FilterChips`, `BusinessCard`, `BusinessGrid`, `EmptyState`, `Footer` |
| Detalhe | `/negocio/:id` | `Header`, `BusinessHero`, `InfoList`, `WhatsAppButton`, `BackLink` |
| Cadastro | `/cadastrar` | `Header`, `TextField`, `SelectField`, `CepField`, `SubmitButton`, `Toast` |

Compartilhados: `Header`, `Footer`, `Loading`, `ErrorMessage`.
